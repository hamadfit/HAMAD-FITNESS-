HAMAD FITNESS — النسخة الأولية المجانية

المحتويات:
- index.html: التطبيق العربي
- manifest.json: إعدادات التثبيت كتطبيق ويب
- sw.js: التخزين المؤقت والعمل دون اتصال بعد أول زيارة

طريقة النشر المجاني:
1) أنشئ مستودعاً عاماً جديداً في GitHub باسم hamad-fitness.
2) ارفع الملفات الثلاثة إلى جذر المستودع.
3) من Settings > Pages اختر Deploy from a branch ثم main و /(root) ثم Save.
4) بعد ظهور رابط GitHub Pages، افتحه في Safari على الآيفون.
5) اضغط مشاركة ثم إضافة إلى الشاشة الرئيسية.

تنبيهات:
- يتطلب التثبيت PWA استضافة HTTPS.
- عداد الخطوات يعتمد على DeviceMotion ويعمل أثناء فتح التطبيق، وهو تقديري وليس بديلاً عن Apple Health.
- GPS يحتاج إذن الموقع واستمرار فتح الصفحة أثناء النشاط.
- البيانات تحفظ محلياً في Safari؛ استخدم تصدير النسخة الاحتياطية.
- لا توجد مزامنة سحابية أو إشعارات مجدولة مضمونة في هذا الإصدار.
